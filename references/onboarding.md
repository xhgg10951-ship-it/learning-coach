# 画像构建与新建目标

## 1. 基础画像（只做一次）

如果 `learning-hub\profile.md` 不存在，先进行基础访谈。**一次性**列出下面的问题，让用户一起回答（可以跳过任意项）：

- 称呼
- 身份：学生（年级/专业）/ 在职（行业/岗位）/ 其他
- 教育与专业背景、已掌握的相关技能
- 资料语言偏好（默认：尽量中文）
- 偏好的资料形式：书 / 官方文档 / 视频课 / 交互式教程
- 预算：只用免费资料 / 可接受付费书籍或课程

按 [profile 模板](../resources/templates/profile.md) 整理，预览后写入。

## 2. 目标补充画像（每个目标一次）

询问：
- 目标描述：想学什么，学到什么程度（如“能独立用 Python 做数据分析”“通过 N2”）
- 动机：考试 / 求职 / 工作需要 / 兴趣
- 截止日期（可以没有）
- 当前水平自评，以及已经学过的内容
- 每周大约可用时间（小时）
- 是否需要和基础画像不同的偏好（语言、资料形式）

## 3. 可选快速水平测试

询问用户是否愿意做 5~10 道题来校准水平（约 10 分钟）：
- 题目覆盖从入门到目标水平的梯度，一次给一题，或者一次性全部给出（由用户选择）
- 根据作答情况给出：已掌握的部分 / 薄弱的部分 / 建议的起点
- 结果写入 `goal.md` 的「水平测试」一节；用户跳过时写“未测试，以自评为准”

## 4. 后续

按 [goal 模板](../resources/templates/goal.md) 写入 `goals\<slug>\goal.md`，然后依次执行：
1. [syllabus.md](./syllabus.md)：生成大纲
2. [planning.md](./planning.md)：生成月目标和当月的周目标

## 画像自动更新

每次学习结束写入笔记后，如果发现画像信息有变化（水平提高、可用时间变了、偏好变了），在 `goal.md` / `profile.md` 的「更新记录」里追加一行：`- YYYY-MM-DD: <变化> （依据：sessions/xxx.md）`，并同步修改对应字段。
