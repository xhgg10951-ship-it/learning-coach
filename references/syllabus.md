# 大纲与资料

## 1. 生成大纲的步骤

1. 读取 `profile.md` 和 `goal.md`。
2. **联网调研**（必须用搜索/抓取工具，不能只凭记忆）：
   - 该领域的权威知识体系：官方学习路径、考试大纲、名校课程大纲、权威教材目录
   - 如果是考试类目标，**以最新年份的官方考试大纲为准**
3. 组织结构：**阶段 → 知识模块**
   - 阶段：如 入门 / 进阶 / 实战（可以按领域调整）
   - 模块编号 `S<阶段>-M<序号>`，如 `S1-M3`
   - 每个模块包含：学习内容要点、**掌握程度**（了解 / 理解 / 能应用 / 能精通）、**资料**、**验收标准**（可检验的行为，如“能不查文档写出 X”“能做对某真题集 80%”）、预计耗时（小时）
4. 根据水平测试结果，把已掌握的模块直接标记为 `[x]`，并注明“水平测试已掌握”。
5. 核算总耗时 ÷ 每周可用时间，判断能否在截止日期前完成。完不成时给出两个方案：缩减范围（标出可选模块）或延长时间。
6. 按 [syllabus 模板](../resources/templates/syllabus.md) 预览，用户确认后写入。

模块状态标记（脚本依赖，不要改格式）：`[ ]` 未开始，`[~]` 进行中，`[x]` 已掌握，`[-]` 已跳过/移出范围。

## 2. 资料规则（硬性）

每条资料必须包含以下全部字段：

| 字段 | 要求 |
|---|---|
| 名称 | 正式名称 |
| 作者/机构 | 真实作者或发布机构 |
| 版本 | 版本号 / 出版年 / 文档对应的软件版本 |
| 位置 | URL（必须实际打开过）或 ISBN |
| 范围 | 具体章节 / 小节 / 页码 / 视频集数与时间段 |
| 程度 | 读到什么程度：通读 / 精读并完成习题 X / 只看 X 节 |
| 核验 | `✅ 已核验 YYYY-MM-DD` 或 `⚠ 未验证（原因）` |

来源优先级：**官方文档 > 权威教材 > 名校/官方公开课 > 知名社区的优质教程**。不使用来源不明的博客、营销号、过期教程。

语言：按偏好优先中文。中文资料（官方中文文档、权威教材的中文版、国内名校课程）**也必须满足权威、最新的要求**。如果中文资料版本落后（如译本对应旧版）或不够权威，改用英文原版，附一段中文导读（该章讲什么、重点、术语对照），并注明“为何不用中文资料”。

## 3. 核验流程

对每条资料：
1. 用 `read_url_content` 或搜索打开 URL，确认页面存在、内容与描述一致。
2. 确认版本最新：对照官方发布页、出版社页面或软件的当前稳定版本。文档类资料优先链接到 stable/latest 版本页，而不是旧版本路径。
3. 章节号、标题要以实际目录为准（书籍查出版社页面或目录；课程查课程主页）。
4. 核验不了（如付费书无法查看目录）→ 标注 `⚠ 未验证`，并说明哪些字段未核实。

用户说「核验资料」时：对指定目标的 syllabus 中全部资料重新执行一遍核验，输出一张变更表（失效 / 有新版本 / 正常），确认后更新。

## 4. 水平不足时的替代

用户反馈“看不懂 / 太难”时：
1. 优先找**更浅显的权威资料**（如官方入门教程、入门级教材的对应章节）。
2. 或者由 AI 写一份简明讲解，**每个关键论断都标注原文出处**（资料名 + 章节），讲解末尾注明“本讲解为 AI 总结，以原文为准”。
3. 替代资料同样要记录到 syllabus 对应模块下，标注“替代资料”。
