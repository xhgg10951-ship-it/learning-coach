# 学习会话

## 开始学习

1. 确定目标（多目标时让用户选）。
2. 读取 `plan.md`（当前周）、`syllabus.md`（相关模块的资料），以及 `sessions\` 中最新的 1~2 篇笔记。
3. 执行 [planning.md](./planning.md) 第 4 节的偏离检查（顺延、提示重排）。
4. 输出**主题卡**：

```markdown
## 📘 本次主题：<主题>
- 对应周目标：W41-2 <内容>（模块 S1-M3）
- 建议时长：约 X 分钟（可随时结束）
- 要看的资料：<资料名> 第 X 章 X.X–X.X 节 <URL>（读到什么程度）
- 学完应该能：<验收行为>
- 🔥 热身（可跳过）：针对上次的薄弱点「…」出 1~2 道题
```

5. 用户可以说“换一个”（换成本周另一条目标），或直接说想学的内容，**以用户为准**。

> 不要求一次学完整个周目标；主题的粒度是“一次坐下来能推进的一块”。

## 学习中

- 自由答疑：解释要准确；涉及具体规范、API、数据的，优先引用资料原文或官方文档，必要时联网核实。
- 用户索要练习时：按当前模块的掌握程度出题，用户作答后批改、讲解错误原因；记录题目、作答结果和对错。
- 不强制教学循环；只有在用户说“我懂了”但前面的作答暴露出误解时，才温和指出。
- 默默记录要写进笔记的内容：知识点、练习、错误、疑问、用到的资料。

## 结束学习（用户说「结束 / 生成笔记 / 今天就到这」）

1. 按 [session 模板](../resources/templates/session.md) 起草笔记，**只写本次会话中实际发生的内容**：
   - 实际学习内容（可以和主题卡不一致）
   - 关键知识点（用自己的话简明总结，重要的地方附资料出处）
   - 练习与结果（题目摘要 / 对错 / 错因）
   - 薄弱点 / 待解决问题（下次热身的来源）
   - 用到的资料与位置
   - 进度判断：对应的周目标是 完成 / 部分完成 / 未推进，模块状态是否变化
2. 预览给用户，允许修改。
3. 用户确认后：
   - 写入 `sessions\YYYY-MM-DD-<topic>.md`（同一天有多次学习时加 `-2` 后缀）
   - 更新 `plan.md` 中周目标的复选框，以及 `syllabus.md` 中的模块状态（模块第一次被学习时 `[ ]→[~]`；满足验收标准时才改为 `[x]`）
   - 必要时更新画像（见 onboarding.md 中的「画像自动更新」）
   - 本周目标全部完成时，按 planning.md 的「超前」规则处理
4. 用一两句话告诉用户更新了什么。

用户没有说结束就离开，或明确说“这次不记录” → 不写任何文件。
