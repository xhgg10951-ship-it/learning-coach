# 月目标 / 周目标规划

## 1. 月目标

- 按 syllabus 的模块顺序和预计耗时，把全部模块分配到各月份（从当前月开始，到截止日期为止）。
- 每月 **3~5 条**可检验的里程碑，每条关联模块编号。
- 后续月份只写月目标，**不细化到周**。

## 2. 周目标（滚动规划）

- **只细化当前月**的各周；进入新月份后（或用户主动要求时）再细化下一个月。
- 每周 **2~4 条**，工作量 ≈ 每周可用时间 × 0.8（留出余量）。
- 每条写明关联模块，以及做到什么算完成。
- 跨月的周归属到周一所在的月份。

## 3. 状态标记（脚本依赖）

周目标的复选框：`[ ]` 未开始，`[~]` 部分完成，`[x]` 完成，`[>]` 已顺延（后面写 `→ 2026-W42`），`[-]` 取消。月目标只用 `[ ]` / `[x]` / `[-]`。

## 4. 偏离处理

每次「开始学习」或「查看进度」时，先检查：

- **过期未完成**：上周及更早的 `[ ]`、`[~]` 周目标 → 自动在原处标记为 `[>] → 当前周`，并复制到当前周（编号保持不变，文字后加“（顺延）”）。这一步不需要确认，但要告知用户。
- **需要提示重排**（满足任一条件）：
  - 进入新的月份
  - 顺延累计 ≥ 2 周（同一目标被顺延 2 次，或当前周积压的顺延目标工作量超过一周）

  这时给出两三个方案让用户选择：延长截止日期 / 缩减范围（列出可移出的模块）/ 保持不变。用户选定后再修改 plan.md 和 syllabus.md。
- **超前**：本周目标全部完成时，告知用户，并提议把下周（或下个月）的第一条目标提前拉入本周，自动执行后在会话里说明。
- **计划外学习**：笔记中出现大纲里没有的内容 → 如果能对应到某个模块，就更新该模块；对应不上的，记在 plan.md 末尾的「计划外学习」一节。

## 5. 用户主动调整

「调整计划」：询问调整原因（时间变化 / 目标变化 / 进度原因），给出修改后的差异预览（改了哪些月目标、周目标、模块），确认后写入，并在 plan.md 的「调整记录」追加一行。

按 [plan 模板](../resources/templates/plan.md) 生成。
